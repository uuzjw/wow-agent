## 模块地图

```
wow_agent/
├── agent.py      # 核心循环 + 状态机
├── cli.py        # 入口、命令处理
├── config.py     # 服务商、环境变量
├── indexer.py    # AST 代码索引
├── tools.py      # 工具 Schema + 执行器
├── subagent.py   # 隔离的调研/审查代理
├── todo.py       # 任务树
├── memory.py     # 长期记忆
├── undo.py       # 快照与回滚
├── mcp.py        # MCP 协议
├── session.py    # 会话持久化
├── i18n.py       # 中英文案
└── ui.py         # Rich 终端界面
```

## 设计原则

1. **纯 Python、最少依赖** — 秒级启动
2. **终端原生 UI** — Rich 输出 + prompt_toolkit 输入
3. **本地优先** — 无遥测；可离线
4. **默认安全** — 沙盒默认开启
5. **可扩展** — JSON Schema 工具、MCP 服务
