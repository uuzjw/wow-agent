四类产品都在解决"AI 写代码"，方式完全不同。本页诚实地把格局讲清楚 —— 包括 wow-agent *不*占优的地方。
## 产品格局
| 类别 | 代表 | 核心循环 |
|---|---|---|
| 浏览器聊天 | ChatGPT、Claude.ai | 粘代码 → 聊 → 粘回来 |
| IDE 副驾驶 | Copilot、Cursor Tab | 打字时行内补全 |
| IDE Agent | Cursor Agent、Windsurf | 编辑器内多文件编辑 |
| **终端 Agent** | **wow-agent**、Claude Code、Aider | **目标 → 规划 → 工具 → 验证结果** |
## 逐项对比
| 标准 | 浏览器聊天 | IDE 副驾驶 | IDE Agent | wow-agent |
|---|---|---|---|---|
| 在真实仓库里工作 | 部分 | ✔ | ✔ | ✔ |
| 多文件任务执行 | ✗ | ✗ | ✔ | ✔ |
| 跑测试并验证 | ✗ | ✗ | 部分 | ✔ 状态机 |
| 模型自由（自带 Key/厂商） | ✗ | ✗ | 部分 | ✔ 16+ + 本地 |
| 完全离线运行 | ✗ | ✗ | ✗ | ✔ Ollama/LM Studio |
| 网络隔离执行 | ✗ | ✗ | ✗ | ✔ `unshare -n` |
| 外传防护（拦 push/SCP） | ✗ | ✗ | ✗ | ✔ |
| Agent 改动一键回滚 | ✗ | ✗ | 部分 | ✔ 快照 + 自动回滚 |
| ARM64 / 边缘设备 | ✗ | ✗ | ✗ | ✔ Jetson 实测 |
| 零订阅（自带 Key） | ✗ | ✗ | ✗ | ✔ MIT 免费 |
| IDE 集成（悬停、补全） | — | ✔✔ | ✔ | ✗ 仅终端 |
| GUI / 可视化 Diff | ✔ | ✔ | ✔ | 终端 Diff |
## wow-agent 赢在哪
1. **信任架构**。沙盒 + 外传拦截 + 确认机制 + 回滚，这套纵深防御没有 IDE Agent 默认内置。
2. **主权**。任意服务商、任意 Key，或完全本地 —— 无厂商锁定、无订阅、数据留在本地。
3. **环境**。纯终端 + ARM64 原生意味着服务器、容器、CI、Jetson 开发板 —— 不需要 IDE。
## 别人赢在哪
1. **行内补全**。想要编辑器里按键级自动补全，副驾驶完胜任何 Agent —— 工具层次不同。
2. **可视化体验**。丰富 GUI、图片 Diff、设计预览 —— 终端输出强大但不图形化。
3. **生态成熟度**。成熟产品有更大的插件市场和支持团队。
## 选择指南
| 你是… | 最佳选择 |
|---|---|
| 天天在服务器/SSH/容器里干活 | **wow-agent** |
| 隐私/合规敏感，要本地模型 | **wow-agent** |
| 要自动化多文件任务且带验证 | **wow-agent** |
| 用边缘设备 / ARM64 开发板 | **wow-agent** |
| 想要打字时的自动补全 | IDE 副驾驶 |
| 想要 VS Code 里的图形化 Agent | IDE Agent |
## 组合使用
它们不互斥。常见配置：副驾驶管行内补全，wow-agent 管**任务级工作** —— "实现这个功能，证明它能跑，然后自己收拾干净。"
